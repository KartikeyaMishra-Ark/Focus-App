# Sakura Productivity Dashboard

A pastel Japanese-inspired productivity dashboard built with HTML, CSS & JavaScript.

A single dashboard combining To-Do List, Pomodoro timer, weather, and music into one workspace to improve productivity!

# Features


## To-Do List
- Add and delete tasks
- Press Enter to add tasks
- Mark tasks as completed
- Persistent tasks with Local Storage
- Scrollable task list



## Pomodoro
- 25-minute timer
- Start / stop functionality
- Reset functionality
- Simple distraction-free interface



## Weather
- Search weather by city
- Automatic location detection
- Temperature
- Weather conditions
- Humidity
- Wind speed



## Music Player
- Play / pause music
- Switch between songs
- Volume control
- Progress bar
- Seek through songs



## Design

The dashboard uses a soft Sakura-inspired aesthetic with:

- Pastel colors
- Animated falling Sakura petals
- Sakura tree background
- Glass-like cards
- Rounded components
- Responsive layout

The goal was to make the dashboard feel like a calm workspace rather than a collection of separate apps.
